# Personal Wealth

Статическое веб-приложение для iPhone: капитал, активы, накопления и доходы. Только рубли. Без аккаунтов, сервера, внешних библиотек и сборки.

## Размещение на GitHub Pages

1. Загрузите содержимое этой папки в свой репозиторий GitHub, сохранив `index.html` в корне.
2. Откройте **Settings → Pages → Build and deployment**.
3. Выберите **Deploy from a branch**, нужную ветку и **/ (root)**, затем **Save**.
4. Откройте выданный GitHub Pages HTTPS-адрес.

Относительные пути поддерживают размещение в подпапке репозитория. `.nojekyll` отключает обработку Jekyll. Коммитов и публикации из этого проекта автоматически не выполняется.

Документация: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

## На iPhone

Откройте адрес сайта в Safari → «Поделиться» → «На экран Домой». Приложение будет открываться с собственной иконкой. После первого успешного открытия и завершения загрузки ресурсов приложение может работать без сети благодаря service worker. В приватном режиме и при запрете хранилища доступность сохранения и офлайн-режима зависит от браузера.

## Использование

- **Главная:** общий капитал, структура портфеля, активы и накопления. У объекта есть название, тип, текущая сумма и необязательный комментарий. Сумма меняется через «Изменить».
- **Аналитика:** доход за последние 12 месяцев, график и категории за 6/12/24 месяца, средний доход, добавление, изменение и удаление доходов. Доходы содержат только месяц и год; каждый доход независим от активов. Все записи доходов доступны ниже графика, в том числе за пределами выбранного периода.
- **Ещё:** JSON-копия, восстановление, CSV доходов, подсказка по установке на домашний экран.

Капитал — сумма текущих сумм активов и накоплений. Доходы сами по себе капитал не увеличивают. Последние 12 месяцев включают текущий месяц; будущие месяцы не включаются в итоги. Средний доход учитывает месяцы без доходов. Суммы хранятся в целых копейках, итоги считаются через BigInt. График показывает месяцы и годы, без дней.

## Хранение и резервные копии

Финансовые данные находятся в браузере устройства, в localStorage, и не отправляются на GitHub. Разные браузеры, устройства и адреса используют отдельные хранилища. Регулярно сохраняйте JSON-копию в «Ещё». Для переноса с локальной версии на опубликованную используйте экспорт и восстановление. Очистка данных сайта удаляет портфель.

Старая веб-копия в рублях преобразуется автоматически: берутся текущие суммы, у доходов остаются месяц и год. Привязки активов, ожидаемый/пассивный доход, справочники и история изменений не переносятся. Исходный ключ старого хранилища остаётся нетронутым. Копии в другой валюте автоматически не конвертируются.

Не загружайте личные JSON- или CSV-копии в публичный репозиторий. Файлы приложения не содержат финансовых данных.

## Локальный запуск

В папке проекта выполните:

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

Откройте http://127.0.0.1:8765. Xcode и Apple ID не нужны.

## Проверка и обновление

```sh
node --test tests/core.test.cjs
node --check app.js
node --check sw.js
```

В `sw.js` меняйте суффикс `CACHE` при обновлении ресурсов, чтобы установленное приложение получало новую версию офлайн-файлов.
